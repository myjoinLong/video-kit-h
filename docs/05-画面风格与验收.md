# 05 · 画面风格与验收

## 风格基准（JohnHeibel / ClaudeAnimationBase 的可执行版）

- **手工感**：所有形状由可见笔触构成，边缘不规整；平涂色块带轻微不均；背景是带纤维颗粒的纸面。禁止完美直线 / 完美圆 / 均匀渐变。
- **永远活着**：每帧至少有一个元素在动；主角有锁拍呼吸；墨线每 **1/12 秒重绘一次**（每 2 帧，偏移 1–3 px）；镜头有极轻微漂移。禁止静止帧。
- **严格平面 2D**：禁止 3D 投影、透视旋转、景深、数码发光。纵深只用「遮挡 / 缩小到 60–80% / 偏冷变淡」三种手段；转身用绘制好的关键视角切换。
- **一支完整的片子**：全片同一个手绘世界、一条色彩弧、屏幕方向一致、结尾回扣开头但状态反转。
- **为观众计时**：一个 read ≥ 0.400 秒，落地停顿 ≥ 0.200 秒；动作可以快，含义必须被按住。
- **十二原则**：预备、挤压拉伸、缓入缓出带回弹、重量、弧线、跟随与重叠、避免孪生、重拍形变 ≥ 12%、强关键姿势、先演思考、次要动作不盖主戏、表情四步切换。

## 锁定色板（13 色，不新增色相）

`paper #F4EAD6` · `ink #2E2A33` · `clay #D97757` · `clayDk #B4533A` · `clayLt #E9A285`
`creamLite #FBF3E2` · `sky #A8C8DC` · `indigo #5A6B8C` · `violet #8C8496`
`teal #6FA9A0` · `tealLt #8FC8C0` · `ochre #E8B44A` · `rose #D98A8A`

全片**无纯黑 `#000000`、无纯白 `#FFFFFF`**，饱和度 ≤ 65%、明度 ≥ 55%。
唯一允许的"光"是画在颜料层之下的暖色加色光晕，纸上颗粒仍透得出来。

## 字幕是画面元素，不是字幕轨

- 每行要点拆成 2–3 张独立手绘分卡，各自入场 / 离场，同屏 ≤ 3 张
- **12 形态**（手写连笔、空心描边、干笔刷、逐字母散开、气泡框、飘带、贴纸、印章、单字巨化、拟物化、双描边、撕纸拼贴）
- **12 位置区** + **12 出入场**，讲解片固定在底部信息带内轮换（竖屏为 3 列网格带）
- **4 质感**（干笔 / 湿水彩 / 中等水分 / 最亮湿水彩），每个大拍 8–12% 字号脉冲
- 禁止：静态字幕、固定底部白字黑边、系统字体层、整行一次性出现、卡拉 OK 式只变色

## 通用验收：26 项（`tools/verify.mjs`）

| 组 | 判据 |
|---|---|
| 1 交付 | 时长 ±0.100 s、帧数、画幅、帧率 |
| 2 音轨 | AAC 44.1 kHz 立体声、不超片长、从 0 开始 |
| 3 数据 | 大拍 / 细分拍 / 小节 / 乐句数量、歌词锚点、镜数、每镜单一镜头运动、缩放 ≤ 1.14 |
| 4 转场 | 数量 = 镜数 + 1、无硬切、无连续 3 次重复 |
| 5 字幕 | 色彩弧、卡数 ≥ 行×2、形态/入场/离场 ≥ 10 种、位置 ≥ 8 区、质感 ≥ 4 种、同屏 ≤ 3、Z5 恰好 1 次、生成器断言干净 |
| 6 画面 | 纯黑 / 纯白像素 = 0、跨 3 帧必有变化（排除 on-twos 造成的假静止） |

## 交付专项（`tools/verify-delivery.mjs`）

两版成片存在 / 时长 / 帧数 / 画幅 / AAC 立体声 / 音轨等长且从 0 开始 / **数字静音**（≤ −70 dB，可被旁白替换）/ 26 项报告全过；
旁白稿三件套齐全、时间码连续覆盖全片、每段语速 120–300 字/分、稿子标注静音轨替换方式。

## 必须人工确认的三项（机检查不了）

1. 艺术连贯性、画面与稿子的语义对应 —— 必须逐镜看
2. 墨线 12 次/秒沸腾与 1–3 px 抖动的手感 —— 必须逐帧看
3. 你放入的音频 / 字体 / 配音的授权 —— 见 `docs/06-版权与授权.md`

**机检全过 ≠ 全片连续试看试听通过**。每期 `notes.honesty` 必须写清实际做到了哪一步。

## 命令

```bash
node tools/verify.mjs --config episodes/<slug>/project.json \
  --file episodes/<slug>/out/<name>-16x9.mp4 \
  --report episodes/<slug>/out/verify-report-16x9.json
node tools/verify-delivery.mjs --episode episodes/<slug>
npm run check        # 语法、路径、依赖、期次完整性、INDEX 同步
```
