# 06 · 版权与授权

## 本仓库

- **代码与文档**：MIT（`LICENSE`）。可自由使用、修改、分发，保留版权声明即可。
- **仓库内不含任何第三方音频**。占位音轨是脚本用 ffmpeg 生成的 240 秒数字静音，成片音轨同样为静音。
- **示例稿子、分镜、信息图文案**：本项目原创，随代码按 MIT 使用。
- **渲染出的画面**：由仓库代码逐帧绘制，含手绘主角与信息图；不含任何现成图标、贴纸、截图或素材库图片。

## 你需要自己负责的

| 素材 | 说明 |
|---|---|
| 你替换进去的音乐 / 音效 | 需自行取得词曲、录音制品与同步授权；CC BY 类许可要按许可署名 |
| 你录的旁白 | 你自己的声音没问题；若用 TTS，确认服务条款允许商用与分发 |
| `voice/reference-vo.*` 参考音 | edge-tts 在线合成，**仅用于内部对轨与试看**，不是成片配音；对外发布前确认服务条款。见 `docs/08-音频与配音.md` |
| 人声克隆 | 声纹属于个人生物特征，需本人明确授权；本项目不提供克隆模型，也别拿别人的声音做 |
| 字体 | `auto` 模式使用系统字体，不随仓库分发。若把 `.ttf` 放进 `assets/fonts/` 并提交，必须确认该字体许可允许再分发 |
| 参考风格 | 本片视觉基准参考 JohnHeibel / ClaudeAnimationBase 的公开风格指南；"参考风格"不等于复制其角色与素材，本片主角与信息图均为独立绘制 |

## 发布前自查

- [ ] 成片音轨里的音乐 / 配音授权清晰，CC BY 类已署名
- [ ] 若附带字体文件，许可允许再分发
- [ ] 稿子里引用的数字、案例、第三方名称已核实
- [ ] `manifest.json` 的 `notes.honesty` 写明了未完成项与授权状态
