# 03 · 配置与信息图

## 两份 project.json 由编译器生成，不要手改

`project.json`（16:9）与 `project-9x16.json`（9:16）由 `tools/build-episode.mjs` 从 `episode.json` 生成。
要改参数请改 `episode.json` 再重新 build。

关键字段：

| 字段 | 16:9 | 9:16 | 说明 |
|---|---|---|---|
| `layout` | `16x9` | `9x16` | 决定画幅 1920×1080 / 1080×1920 |
| `style.heroPlacement` | `{x:250,y:880,u:22}` | `{x:514,y:1010,u:22}` | 讲解员在左下，给中间信息图让位 |
| `style.cardBand` | `{xMin:400,xMax:1560,y:905,jitterY:26}` | `{xMin:110,xMax:970,y:1730,rows:3,rowGap:76,jitterY:22}` | 竖屏用 3 列网格带，按同屏顺序分格 |
| `style.portraitInfographics` | `true` | `true` | 9:16 走重新排版的竖版信息图 |
| `layouts.9x16.kfScale` | — | `0.72` | 竖屏字幕字号倍率，避免长词撑爆 1080 宽 |
| `generated.*` | `generated/` | `generated-9x16/` | 两版各有独立的规格与字幕卡 |
| `out` | `...-16x9.mp4` | `...mp4`（渲染器自动加 `-9x16`） | 不要手动加后缀 |

## 元素库（`shots[].elements`）

横版与竖版共用同一批**名字**，9:16 时自动换成竖版画法。

| 名字 | 内容 |
|---|---|

## 怎样加一张新信息图

1. 在 `src/props/explainer.mjs`（横版）与 `src/props/portrait.mjs`（竖版）各写一个纯函数 `(g,t,o)=>void`；
   复用 `panel / handText / arrow / stamp / check / cross / RECT` 这些已导出的原语。
2. 在 `src/timeline/props.mjs` 的 switch 里注册名字，并加入 `INFO_NAMES`（让竖屏跳过横版画法）。
3. 在 `src/props/portrait.mjs` 的 `PANELS` 里注册竖版画法。
4. 在 `episode.json` 的 `shots[].elements` 里使用这个名字，重新 build → 静帧目视 → 渲染。

**规则**：只用 13 色锁定色板、墨线随 `t` 做 12 次/秒沸腾、纯函数（同一 `t` 必得同一帧）、禁止文字素材化截图与 UI 图标。

## 9:16 为什么不是裁切

- 世界按 1.25 倍重新取景，横向锚点收拢（`VX` 压缩 0.52）、纵向铺开（`VY` 1.02），形状**不做非等比拉伸**。
- 横版信息图若在竖屏直接画，会被相机压到画面中段并裁掉左右；所以竖屏改在**屏幕空间**重画一套竖版信息图（`drawPortraitPanel`），标题、卡片、表格、清单全部按 1080×1920 重排。
- 字幕带从"12 个横向槽位"改成"3 列网格带"，按同屏顺序从左到右排，尾卡独占中央。
- 主角位置、字号倍率、安全边距都按竖屏单独配置。

## 字体

`src/core/font.mjs` 自动探测：拉丁手写体（Ink Free / Segoe Print / Comic Sans / macOS 手写体）+ 中文楷体（Windows `simkai` / `STKAITI`、macOS `Kaiti SC`、Linux Noto CJK）。
想让任何机器渲出来一模一样，把一份**有权分发**的 `.ttf` 放进 `assets/fonts/`，在 `episode.json` 里设 `fontFile` / `fontFileCJK`（当前由 project 生成，值为 `auto`）。
